# Parity-oracle release vocabulary

GENERATED by `tools/oracle/check_boundary.py` — do not edit by hand.

Every value below is a clean-side constant. A record from the custody
side selects among them; it never supplies a string that is released.

## Record shape

```json
{"schema":"automonique.oracle-release/v1","outcome":"<outcome>","differences":[{"field":"<field>","relation":"<relation>","magnitude":"<magnitude>"}]}
```

At most **4096** bytes, exactly these three keys, no
numbers, and no key or value outside the tables below.
