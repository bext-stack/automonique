not represent that a mark is registered. Software and documentation licences do
not grant trademark rights.

## Uses allowed without separate permission

You may:

- truthfully refer to the unmodified Automonique product;
- state that software is compatible with, integrates with, or is derived from
  Automonique when the statement is accurate and does not imply endorsement;
- reproduce the wordmark as necessary in copyright and licence notices; and
- link to the official project using plain text.

These uses must be no more prominent than your own brand and must not imply
sponsorship, certification, partnership, or origin.

## Uses requiring written permission

Written permission is required to:

- use an Automonique logo, mascot, or visual identity outside an unmodified
  official distribution;
- use an Automonique mark in a company, product, service, package, domain,
  application, social-media account, event, or merchandise name;
- describe an offering as official, certified, endorsed, or partnered;
- distribute modified software under Automonique branding; or
- use the marks in advertising beyond truthful nominative reference.

Modified distributions and hosted offerings must adopt distinct names and
branding. They may use a plain-text compatibility statement if accurate.

Requests and reports of suspected misuse must use the verified private contact
channel published by <https://github.com/bext-stack>.

Use ™ for claimed marks. The ® symbol may be used only where and when the
relevant mark is registered for the applicable goods or services.
