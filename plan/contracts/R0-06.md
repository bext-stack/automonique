## Objective

Create a machine-readable, date-stamped inventory for the locally available
Jcode, Claude, Codex and opencode programmatic surfaces without consuming a
model call or exposing credentials. Record observed versions, protocols,
schemas, lifecycle commands, authentication state categories, capabilities,
unsafe/experimental methods and representable fallbacks.

## Sources

Use installed command help/schema/version output and current public first-party
documentation. Do not use the prior implementation, private transcripts,
credential values or reconstructed behavior.

## Scope

In scope:

- non-mutating version, help, schema and health probes;
- raw public/installed schema artifacts with provenance and digest;
- normalized capability rows tied to exact provider version and integration
  mode;
- explicit unavailable/unknown results and a rerun command.

Out of scope: authentication changes, model calls, session transcript capture
(`R0-07`), adapter implementation or declaring undocumented behavior stable.

## Verification contract

| Check | Expected |
|---|---|
| Versions | each provider has an observed version or `null` with reason |
| Native surfaces | protocol, transport, schema source and stability class recorded |
| Capabilities | create/resume/observe/steer/cancel/approval/reconnect/model/usage fields answered per mode |
| Authentication | state category recorded without credential or account identifiers |
| Fallbacks | ordered fallback and lost guarantees recorded without silent downgrade |
| Reproducibility | rerun produces the same normalized inventory for unchanged binaries/schemas |
| Provenance | every raw artifact names public/installed source, capture command and SHA-256 digest |

## Forbidden shortcuts

- making a paid or real model call;
- reading provider credential files or printing environment values;
- treating help text as proof of runtime semantics;
- collapsing unknown, unavailable and unsupported into one value.

## Completion evidence

Normalized inventory, raw sanitized probe artifacts, version/schema digests,
rerun comparison and an explicit list of questions deferred to `R0-07`.

## Stop conditions

Stop a provider probe if it requires authentication mutation, network side
effects, a model call, private data or acceptance of unreviewed terms.
