## Objective

Add the first product workspace members and deterministic offline checks without
adding another harness layer. The protocol and policy crates are product code;
the existing lab remains a development adapter.

## Verification contract

| Check | Expected |
|---|---|
| Workspace | locked offline metadata, check and tests include both product crates |
| Quality | formatting and strict Clippy pass without new allowances |
| Boundary | product crates expose no shell, credential, provider or network execution surface |
| Licence | product Rust files are `Elastic-2.0`; SDK files are `Apache-2.0` |
| Reproducibility | regenerating `Cargo.lock` offline is byte-identical |

## Stop conditions

Stop on an unavailable offline dependency, a path outside the lease, a licence
boundary violation, or any need to weaken an existing check.
