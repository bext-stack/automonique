## Objective

Prove with a synthetic runner that execution-host identity is independent of a
particular control-plane connection, remains discoverable after controller
disconnect/reconnect, and can be cancelled with every descendant through a
typed backend contract.

The direct-process backend is required. cgroups, systemd transient units,
containers, remote executors, and stronger isolation are optional adapters that
must report their actual capabilities.

## Scope

In scope:

- fixture controller, runner and child processes below `spikes/execution-host/`;
- opaque host identity, protected control channel and atomic status;
- controller disconnect/reconnect, typed cancel and descendant cleanup;
- explicit `null` results for unavailable cgroup or supervisor features.

Out of scope: production provider calls, persistent services, privileged
process control, sandbox policy, or a generic command execution interface.

## Verification contract

| Check | Expected |
|---|---|
| Environment | kernel/process mode and unavailable optional features recorded |
| Reconnect | host identity and status survive controller disconnect/reconnect |
| Discoverability | opaque host ID resolves to expected control channel and process tree |
| Cancellation | one typed cancel stops runner and descendants within timeout |
| Failure | launch failure creates no false-running state or surviving child |
| Cleanup | no fixture process, socket or temporary state remains |

## Forbidden shortcuts

- using a shell command supplied by fixture output;
- killing only the parent PID;
- treating an unavailable optional supervisor as a failure of the direct backend;
- using a production process or credential.

## Completion evidence

Fixture source, exact invocation, process-tree observations, reconnect result,
injected failure, cancellation latency, optional capability results and cleanup.

## Stop conditions

Stop before mutation if descendant ownership cannot be bounded without
privilege or if the typed backend contract would need arbitrary argv from model output.
