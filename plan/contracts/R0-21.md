## Objective

Emit reproducible `automonique.dev-metrics/v1` manifests and compact commit
trailers covering correctness, performance, prompt economics, safety and
environment provenance without rewarding commits, lines, tokens or agent count.

## Verification contract

| Check | Expected |
|---|---|
| Schema | every required metric is measured or `null` with reason |
| Digest | manifest content deterministically produces the trailer digest |
| Baseline | regressions and explicitly accepted flat metrics are distinguished |
| No reward proxy | commits/lines/tokens/agent count are context only |
| Privacy | secrets, prompts, private paths and account identifiers are rejected |
| Reproducibility | identical evidence produces byte-identical manifest/trailers |
| Tamper detection | post-attestation evidence change invalidates the digest |

## Forbidden shortcuts

- changing a metric and using it to judge the same candidate;
- converting missing measurements to zero;
- storing hidden reasoning, credentials or private transcripts;
- optimizing contextual counts as progress scores.

## Completion evidence

Schema, golden-free deterministic fixtures, regression/tamper/privacy rejection
transcripts and two byte-identical generations.

## Stop conditions

Stop when a required metric lacks a lawful collection method; record `null`
with reason and request an owner decision if it is promotion-critical.
