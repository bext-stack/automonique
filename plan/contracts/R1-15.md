## Objective

Define the five distinct lifecycle identities the scheduler and reporter depend
on — work, attempt, execution host, provider session and turn — together with
the host state machine, its attempt-scoped versus session-scoped lifetime, the
idle-TTL and hibernation semantics, and the classification that decides after a
restart whether a session is resumable, hibernated, terminally interrupted or
requires reconciliation. A missing local process is never called "running".

This slice defines identities, states, legal transitions and classification
rules only. It spawns no process, allocates no unit, opens no socket, reads no
`/proc` and starts no timer. It fixes the vocabulary so that `R2` can implement
supervision against a state machine that was decided in advance.

## Lifecycle contract

- `work`, `attempt`, `execution host`, `provider session` and `turn` are
  distinct types that do not interconvert. A retry appends a new attempt with a
  new identifier and its own attempt number; it never overwrites a prior
  attempt, so earlier evidence remains addressable forever.
- Host lifetime is an explicit two-valued property: `attempt`-scoped hosts
  bound one attempt's process boundary, `session`-scoped hosts serialize
  multiple turns. Lifetime is fixed at construction and cannot be changed
  afterwards, because a host that changes lifetime mid-life has no meaningful
  boundary.
- Host identity includes tenant, provider account, workspace security context
  and boot identity. A resumable provider session may attach only through an
  identical boundary; attaching through a weaker or merely different one is a
  typed refusal naming the differing component. This is the rule that stops a
  resumed session from crossing a tenant.
- The host state machine covers starting, ready, busy, idle, hibernated,
  stopping, stopped, failed and lost. Legal transitions are declared as an
  exhaustive table; an undeclared transition is a typed error, not a permissive
  default. Terminal states are terminal: nothing leaves `stopped` or `failed`.
- A run has zero or one execution host. The host identifier is absent while
  pending or admission-blocked and may remain absent for a pre-launch
  cancellation. Assignment is expressible as an atomic pairing with the
  `pending -> starting` transition, so a state where a run is `starting` with
  no assigned host is unrepresentable.
- Idle TTL and hibernation are declared as bounded durations with explicit
  expiry instants derived from a supplied clock reading — the value layer never
  reads a clock itself. Expiry is a pure function of the recorded instants, so
  the same inputs always classify the same way.
- Post-restart classification is total over the recorded evidence and returns
  exactly one of `resumable`, `hibernated`, `terminally_interrupted` or
  `reconciliation_required`. Absent or ambiguous evidence classifies as
  `reconciliation_required`, never as `resumable` and never as `running`. The
  classification's inputs are authoritative provider capability and recorded
  evidence, not the presence of a local process.
- Serialization keys are claimed before `queued -> starting` and released only
  on terminal work state or verified host loss. A reload transfers ownership;
  it does not delete a claim, so a paused old generation cannot act after
  expiry.

## Verification contract

| Check | Expected |
|---|---|
| Identity distinctness | work, attempt, host, session and turn identities do not interconvert, proven by compile-fail coverage |
| Retry appends | a retry produces a new attempt identifier and number; no path overwrites a prior attempt's evidence |
| Lifetime immutability | lifetime is fixed at construction; a change attempt is a typed error |
| Boundary-bound attach | attaching a session through a differing tenant, provider account, workspace context or boot identity is refused with the component named |
| Transition legality | the legal-transition table is exhaustive; undeclared transitions error; terminal states have no outgoing transitions |
| Host assignment atomicity | a run in `starting` with no assigned host is unrepresentable; absent host identity is legal only while pending, admission-blocked or pre-launch cancelled |
| Expiry purity | idle TTL and hibernation expiry are pure functions of supplied instants; no clock is read inside the value layer |
| Restart classification | classification is total and returns exactly one outcome; absent or ambiguous evidence yields `reconciliation_required`, never `resumable`, and no input path yields "running" from a missing process |
| Claim lifecycle | serialization claims release only on terminal work state or verified loss; reload transfers ownership without deleting a claim |
| Quality | workspace tests, strict Clippy and formatting pass offline with no new allowance, network access, runtime dependency or lockfile drift |

## Compatibility and evidence

Use only the permitted product requirements, the recorded `R0-03` and `R0-04`
lifecycle spike evidence, the structural migration map and synthetic fixtures.
`docs/product-plan/requirements/state-and-protocols.md` § Attempts, execution
hosts and event cursors is the source for the identity split, the state
vocabulary, the host-identity components and the post-reboot classification
rule. Record the full transition table with one covering case per legal and
illegal edge, and the classification matrix with its evidence inputs. No
process is spawned and no `/proc` is read; a test that does either has left the
lease.

## Stop conditions

Stop on any need for a new dependency or `Cargo.lock` change, interconvertible
lifecycle identities, a retry that overwrites prior evidence, mutable host
lifetime, a session attach across a differing boundary component, a permissive
default for an undeclared transition, an outgoing transition from a terminal
state, a representable `starting` run without a host, a clock read inside the
value layer, any classification path yielding `resumable` or "running" from
absent evidence, a claim released without terminal state or verified loss, a
process spawn or `/proc` read, a licence-boundary violation, a forbidden
clean-room input, or any path outside the lease.
