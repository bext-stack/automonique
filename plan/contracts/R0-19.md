## Objective

Build a proposal-only development harness that consumes the executable DAG,
persists attempts/checkpoints/evidence, allocates isolated worktree and file
leases, brokers bounded builds and typed local Git operations, and exposes a
minimal TypeScript scenario client. It must work without the unfinished product
daemon and without protected-branch credentials.

## Verification contract

| Check | Expected |
|---|---|
| Durable resume | queued/running work and checkpoints survive process restart |
| Lease exclusion | overlapping path leases are rejected or serialized |
| Immutable base | source drift invalidates the candidate before commit |
| Build budget | CPU/time/disk/PID ceilings terminate and record bounded failure |
| Git broker | only leased paths at expected base can enter a local candidate commit |
| Forbidden Git | push, merge, force, remote edit and history rewrite requests are rejected |
| Provider boundary | inventory-selected modes start only with declared capability/budget policy |
| Scenario client | TypeScript client can select, observe, resume and cancel a synthetic unit |
| Recovery | interrupted broker operations reconcile without duplicate commit/effect |

## Forbidden shortcuts

- generic shell or arbitrary argv generated from model output;
- direct worker access to Git credentials or shared mutable build caches;
- in-memory-only work state;
- treating a self-reported agent result as terminal evidence.

## Completion evidence

Unit/integration results, restart transcript, conflict/lease denials, resource
termination, Git denial matrix, schema/client conformance and remaining provider
limitations.

## Stop conditions

Stop on any requirement for protected credentials, paths outside the lease,
unbounded host execution or a provider behavior absent from `R0-06` evidence.
