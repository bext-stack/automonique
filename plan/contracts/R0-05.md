## Objective

Pin the foreground control-plane and execution-backend lifecycle contracts from
the measured `R0-03` results. Record which guarantees the direct-process
baseline provides, which require an optional supervisor adapter, and the
evidence threshold that would justify making any adapter recommended.

## Verification contract

| Check | Expected |
|---|---|
| Inputs | exact R0-03 evidence digest and environment are cited |
| Baseline | foreground start/readiness/drain/shutdown ownership is defined |
| Adapters | systemd, launchd/container and direct-process capabilities are separated |
| Failure behavior | pre-ready, post-ready, drain-timeout and restart ownership defined |
| Portability | unsupported adapter features do not invalidate core operation |
| Revisit rule | explicit evidence threshold for recommending an adapter |

## Forbidden shortcuts

- selecting a service manager from preference;
- making optional activation/resource features core correctness dependencies;
- deleting contradictory observations;
- implementing a production supervisor adapter in this item.

## Completion evidence

Decision record, evidence links, capability matrix and unresolved risks.

## Stop conditions

Stop if `R0-03` evidence is missing or the proposed baseline cannot run directly
in a foreground test process.
