## Objective

Deliver the first runnable Monique product command: `automonique doctor
[--json]`. It performs bounded, read-only local health checks and returns a
stable typed report. It is not a service and does not start the lab.

## Verification contract

| Check | Expected |
|---|---|
| Invocation | human and JSON modes have deterministic output and exit codes |
| Read-only | no inspected file, directory, socket, database or environment is mutated |
| Safety | symlinked or permissive runtime paths are reported, never repaired |
| Truthfulness | unavailable checks carry a typed reason and are not reported healthy |
| Compatibility | the JSON report uses a versioned `automonique.doctor/v1` schema |
| Tests | healthy, finding, malformed, missing, symlink and permission cases pass offline |

## Stop conditions

Stop on a requirement for credentials, `.env` parsing, network access, mutation
of an inspected path, an unbounded read, or a path outside the lease.
