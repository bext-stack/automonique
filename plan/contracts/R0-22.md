## Objective

Preserve workers, build tasks, queues, leases and evidence across harness
restart; serialize owner-configured candidate integration, invalidate stale
evidence after conflicts, and prove clean abandon/rollback. Protected pushes
and merges remain external.

## Verification contract

| Check | Expected |
|---|---|
| Restart | active work/build/evidence resumes or reaches an explicit reconciled state |
| Lease recovery | expired/orphaned leases cannot permit overlapping writes |
| Serialization | local candidate commits enter a deterministic one-at-a-time train |
| Conflict | changed candidate digest invalidates affected checks/reviews |
| Idempotency | repeated action receipt cannot duplicate commit/integration state |
| Abandon | candidate worktree/state is removed without touching unrelated work |
| Rollback | bad development candidate returns to recorded prior state |
| Protected authority | no harness credential can push or merge protected refs |

## Forbidden shortcuts

- blind retry after ambiguous Git or process outcome;
- retaining stale review/check evidence after a diff change;
- global reset, stash, force or history rewrite;
- treating local commit creation as protected integration.

## Completion evidence

Restart/failure matrix, state snapshots, conflict invalidation, duplicate-action
receipt, abandon/rollback transcript and protected-operation denials.

## Stop conditions

Stop when recovery cannot distinguish applied from unapplied state, or when
progress would require a protected credential.
