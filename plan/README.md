# Historical planning archive

This directory records an earlier executable-plan and autonomous-development
experiment. It contains a work graph, contracts, gates, evidence, decisions,
and the tools that operated on them.

None of it controls current development. Do not claim work, obtain a lease,
select a ready ID, create evidence JSON, run a gate, or update graph state
unless the user specifically asks to work on this historical system.

For ordinary work, follow `AGENTS.md`, the relevant product requirements, and
the current implementation and tests. Historical files may explain why an old
decision was made, but current product behavior and active policy win.

`python3 plan/check.py --verify` remains an optional archive-consistency check.
Its result is not permission to develop, commit, or push.
